WebSummoner

A fast Selenium hub that launches browsers in Docker containers. Video with sound, live screen, logs — built for testing at scale.

Get started → Features Browsers 
$ docker run -d --name websummoner \
    -p 4444:4444 \
    -v $PWD/browsers.json:/etc/websummoner/browsers.json:ro \
    -v /var/run/docker.sock:/var/run/docker.sock \
    websummoner/websummoner:latest
