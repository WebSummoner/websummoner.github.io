WebSummoner

Summon a fleet of browsers into Docker containers. A fast Selenium hub with ephemeral, session-scoped environments.

Get started → Features Browsers 
$ docker run -d --name websummoner \
    -p 4444:4444 \
    -v $PWD/browsers.json:/etc/websummoner/browsers.json:ro \
    -v /var/run/docker.sock:/var/run/docker.sock \
    websummoner/websummoner:latest
